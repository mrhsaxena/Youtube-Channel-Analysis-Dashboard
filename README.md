# YouTube Analytics Dashboard – TheMusicMixs

## Project Overview
This project is an interactive YouTube Channel Analytics Dashboard developed using Microsoft Power BI for the YouTube channel **TheMusicMixs**.

The dashboard helps analyze channel performance, video engagement, audience viewing behavior, and content performance through interactive visualizations and KPI cards.

## Objectives
- Analyze total views and video performance.
- Track likes, comments, and shares.
- Monitor watch time and subscribers gained.
- Compare the performance of individual videos.
- Understand average view duration.
- Explore channel performance using interactive slicers.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- YouTube Studio Analytics

## Dataset
The project uses analytics data exported from YouTube Studio for the period:

**29 October 2025 – 29 October 2026**

The source data includes:
- Video-level performance data
- Daily average view duration by video
- Daily channel-level average view duration

## Dashboard KPIs
- Total Views
- Total Likes
- Total Comments
- Total Shares
- Watch Time (Hours)
- Subscribers Gained
- Thumbnail Impressions
- Average Click-Through Rate (CTR)

## Dashboard Visualizations
- Top 5 Videos by Views
- Engagement Trend
- Average View Duration
- Views Over Time
- Interactive Date and Video Slicers

*Note: Visuals are based on the availability of the corresponding metrics in the exported dataset.*

## Data Preparation
Power Query was used to:
- Import CSV files.
- Clean and rename columns.
- Set appropriate data types.
- Remove the summary Total row from video-level records.
- Prepare data for dashboard reporting.

## Key Learnings
- Data cleaning and transformation using Power Query.
- Creating DAX measures for KPI cards.
- Building interactive Power BI visuals.
- Working with YouTube Studio Analytics exports.
- Designing a dashboard for performance monitoring.
